# Contributing

Thanks for helping improve Grok Tutor as an educational resource.

## Ground rules

1. **Educational intent only** — no offensive tradecraft, no doxxing, no real PII.
2. **Plain language** — samples and UI copy should be understandable to beginners.
3. **No secrets** — never commit API keys, `.env` files, tokens, or private datasets.
4. **Craft accuracy** — field examples should match real job communication without insider soup.

## Dev loop

```bash
npm install
npm run dev
npm run typecheck
```

Open a PR against `main` with a short description of the learning improvement.
