# Security

## Reporting

If you discover a vulnerability in this educational app, please open a **private** security advisory on GitHub or contact the AdventureNLearn maintainers through GitHub — do not file a public issue with exploit detail.

## Secrets

- API keys (`XAI_API_KEY`, etc.) must live only in server environment variables.
- Never commit `.env` files.
- Rotate any key that may have been exposed.

## Scope

This project is an educational tutor. Please do not submit pull requests that add attack playbooks, weaponized payloads, or real personal data.
